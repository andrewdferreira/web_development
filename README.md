# Desenvolvimento Web

Repositório destinado às atividades, exercícios e projetos desenvolvidos durante a disciplina de Desenvolvimento Web na faculdade.

## Objetivos

- Praticar a estruturação de páginas com HTML.
- Aprender e aplicar estilos com CSS.
- Desenvolver interações usando JavaScript.
- Organizar projetos web de forma clara e evolutiva.


Novas aulas e atividades serão adicionadas ao repositório conforme o conteúdo da disciplina avançar.

## Como executar

1. Clone este repositório:

	```bash
	git clone https://github.com/andrewdferreira/web_development.git
	```

2. Acesse a pasta do projeto:

	```bash
	cd web_development
	```

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para visualizar as alterações em tempo real.

## Tecnologias

- HTML5
- CSS3
- JavaScript
